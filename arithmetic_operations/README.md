### Simple Arithmetic Operations

Functions to perform the following:

- **`subtract_numbers`**: Subtracts `b` from `a`.
- **`multiply_numbers`**: Multiplies `a` by `b`
- **`divide_numbers`**: Divides `a` by `b`
- **`even_or_odd_sum`** determines if the sum of two numbers is even or odd
- **`even_or_odd_sum`** determines if the number given is odd
- **`first_num_is_odd`** determines if the first number `a` is an odd number or even number 
- **`positive_number`** determines if the second number `b` is an odd number or even number 
- **`num_is_max`** determines the maximum number between `a` and `b`
