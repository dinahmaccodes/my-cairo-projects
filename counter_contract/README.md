#### Counter Contract

This is for a counter contract <br>
It works by making use of the following functions

- `increase_balance`: to increase the balance by a certain inputed amount
- `increase_balance_by_one`: to increase the balance by one
- `decrease_balance`: to decrease the balance by a certain inputed amount
- `decrease_balance_by_one`: to decrease the balance by one
- `get_balance`: to get the current balance of the counter
- `reset_balance`: to reset the current balance so it will be zero
